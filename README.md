## Выбранный API: Rick and Morty API
Описание: Для проекта был выбран Rick and Morty API. Это RESTful API, которое предоставляет информацию о персонажах мультсериала. В приложении реализовано получение списка героев, поиск по имени и детальный просмотр информации.

---

## Выполненные реактивные сценарии:
1. **Реактивное избранное и синхронизация состояния:** Поток избранных персонажей (`Flow<List<Character>>`) из локальной базы данных Room совмещён с результатами сетевого поиска. При добавлении или удалении персонажа из избранного на любом экране (главный список, экран избранного, детальный просмотр) состояние всех экранов мгновенно синхронизируется и обновляется реактивно, исключая повторные запросы к API. Добавлен интерактивный значок сердечка прямо в элементы главного списка.
2. **История поиска на основе локальной БД:** Добавлена таблица `search_history` в Room для сохранения последних запросов пользователя. При пустом поисковом запросе на главном экране отображается список последних 5 поисковых запросов с возможностью быстрого повторного поиска по клику, удаления элемента истории или полной очистки.

### Использованные источники данных (Flow):
1. `searchQuery` (`StateFlow<String>`) — реактивный ввод в поисковую строку.
2. `statusFilter` (`StateFlow<String>`) — выбранный фильтр по статусу (All / Alive / Dead / Unknown).
3. `favorites` (`Flow<List<Character>>`) — поток из базы данных Room, отслеживающий изменения избранного.
4. `searchHistory` (`Flow<List<String>>`) — поток из базы данных Room с историей поисковых запросов.
5. `retryTrigger` (`SharedFlow<Unit>`) — поток триггера повторного запроса при ошибке.

### Использованные операторы Flow:
* `combine` — объединяет 4 независимых потока для построения итогового состояния `ListUiState`.
* `debounce` + `distinctUntilChanged` — предотвращают дублирующие и слишком частые запросы к API во время набора текста.
* `flatMapLatest` — отменяет предыдущие активные сетевые запросы при поступлении нового поискового запроса.
* `stateIn` — преобразует холодные цепочки в горячие `StateFlow` с учетом жизненного цикла (`SharingStarted.WhileSubscribed(5000)`).
* `map` — преобразует DTO/Entity потоки в удобные для UI доменные модели.
